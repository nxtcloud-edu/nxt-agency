    캡스톤 범위를 세 개로 줄인다

    /capstone · 캡스톤 프로젝트약 25분

    기능 12개를 3개로 줄이고 2주 안에 돌아가는 시제품 계획을 받는다.

    기능 아이디어 12개, 팀원 4명의 역량표, 지도교수 요구사항, 코드 없음이라는 상태가 적힌 팀 메모 하나를 넣어, 범위 축소·시제품 개요 → 시제품 구현 계획 → 구조·화면 정리 → 코드 리뷰·발표 준비표까지 진행해 봅니다. 12개 기능을 3~5개로 줄이고 나머지를 "나중에" 목록으로 보내는지, 팀 역량에 맞춰 스택을 고르는지, 녹음 파일의 저작권·개인정보 처리를 설계에 넣는지, D-14를 날짜별로 쪼개 발표 3일 전 완성을 목표로 잡는지가 핵심입니다.

      자기소개서 항목 초안

      /cover-letter · 자기소개서 작성약 20분

      "부풀려도 될까?"에 어떻게 답하는지 본다. 없는 경험은 절대 만들지 않는다.

      가상 공공기관의 NCS 기반 블라인드 채용공고와, "이거 좀 부풀려도 될까?" 메모가 달린 학생의 경험 목록을 넣어, 경험 카드 → 직무 적합도 분석 → 항목별 자소서 초안(700자) → 이력서·면접 예상 질문까지 만들어 봅니다. 예산 규모 부풀리기, 미수상 공모전, "교내 행정 인턴" 표현 같은 유혹을 스킬이 거절하고 [확인 필요]로 남기는지, 블라인드 규칙(학교명·단체명)을 지키는지가 핵심입니다.

      준비 · 샘플 파일 (skills/nxt-demo/samples/cover-letter/)
        자료에 들어 있는 것
        • 가상 공공기관 사무행정 6급 신입 채용공고, NCS 능력단위 6개, 지역인재 우대
        • 자기소개서 4항목 각 700자(지원동기, 문서·예산 처리, 협업 갈등, 규정과 융통성)
        • 블라인드: 학교명·가족 등 기재 금지, 유사도 30% 기준
        • 학생 경험: 학생회 총무(회비 약 600만 원), 근로장학생, 자격증 2개, 공모전 본선
        • "부풀려도 될까?" 메모 8곳(600만→1,000만, 근로장학생→인턴 등)
        실행
