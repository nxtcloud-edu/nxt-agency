학생의 선행연구 정리를 같이 본다

/literature-review · 선행연구 정리약 25분

같은 데이터를 재사용한 논문 두 편이 근거 하나로 묶이는지 본다.

지도교수 코멘트가 붙은 주제 메모와 후보 문헌 10편을 넣어, 검색 전략서 → 근거 수준이 매겨진 정리표 → 연구 공백·설계 시사점까지 한 번에 뽑아 봅니다. 같은 데이터를 재사용한 논문 2편, 종단 연구와 횡단 연구의 불일치, 학위논문·개념이 다른 논문의 포함 여부를 스킬이 어떻게 처리하는지가 핵심입니다.

준비 · 샘플 파일 (skills/nxt-demo/samples/literature-review/)
    자료에 들어 있는 것
    • 석사 2학기 학생의 주제 메모: 진로결정 자기효능감 → 취업준비행동
    • 연구질문 초안 3개(예측, 학년 차이, 진로장벽 매개)와 지도교수 코멘트 5개
    • 가상 후보 문헌 10편: 메타분석 1, 종단 1, 질적 1, 준실험 1, 학위논문 1, 횡단 5
    • 각 문헌의 설계·표본·측정·핵심 결과(β, r, CI) 정리
    • 1차 선별 후 남은 고민 5가지(척도 불일치, 횡단 자료 해석 등)
    실행
    /literature-review 대학생 진로결정 자기효능감과 취업준비행동, 석사논문 2장, 국내외 최근 10년. 아래 자료를 붙여 넣습니다.

    그 뒤에 topic-brief.md 전체를 먼저 붙이고, 이어서 candidate-sources.md 전체를 붙여 넣으면 됩니다.

    기대 결과

    대상/비교/결과로 구조화된 연구질문과 포함·배제 기준이 담긴 검색 전략서. 10편의 근거 등급·방법의 질·독립성·약한 고리를 매긴 정리표(1번과 3번은 같은 데이터로 표시). "잘 확립됨 / 논쟁 중 / 단일 연구뿐 / 근거 공백"으로 나눈 종합 지도와, 종단 연구의 역인과 결과를 반영한 설계 시사점.

    내 자료로 하려면. 연구 주제와 검색 범위만 알려 줘도 시작됩니다. 이미 모은 문헌이 있으면 저자·연도·제목·설계를 목록으로 붙여 넣으세요.

    공고 분석부터 계획서 초안까지

    /research-proposal · 연구계획서 작성약 30분

    배점표에 맞춰 계획서 목차를 짜고 예산 세목을 채운다.

    가상 중견연구 공고 발췌와 연구책임자 프로필 메모를 넣어, 공고 분석·평가지표 대응표 → 필요성 근거 메모 → 계획서 초안 → 세목별 예산까지 진행해 봅니다. 지원 자격 충족 여부가 애매한 지점, 유형 선택 미정, 데이터 2차 활용 동의 미확인 같은 빈 칸을 스킬이 [기재 필요]·"확인 필요"로 남기는지가 핵심입니다.

    준비 · 샘플 파일 (skills/nxt-demo/samples/research-proposal/)
      자료에 들어 있는 것
      • 한국연구재단 가상 중견연구 공고: 유형별 연 1억~2억, 3년(1+2), 11월 6일 마감
      • 지원 자격: 박사 후 5년 이상, 최근 5년 주저자 SCIE·SCOPUS 5편 이상
      • 평가 배점 100(창의성 25, 구체성 25, 역량 20, 활용 15, 지역 기여 10, 예산 5)
      • 연구자 프로필: 비수도권 부교수, SCIE 4편·KCI 5편, GPU 서버, 민원 텍스트 3만 건
      • 아이디어: 소형 언어모델로 지역 공공 문서 구조화. 유형·인원·IRB 등 5가지 미정
      실행
      /research-proposal 한국연구재단 중견연구 2027년 공고, 주제는 소형 언어모델 기반 지역 공공 문서 구조화, 3년. 아래 자료를 붙여 넣습니다.

      그 뒤에 call-excerpt.md를 먼저 붙이고, 이어서 pi-profile.md를 붙여 넣으면 됩니다.

      기대 결과

      배점 100점을 항목별로 옮긴 평가지표 대응표와 지원/보류 판단, 자격 요건 중 확인이 필요한 항목 표시. 공고 표현으로 다시 쓴 계획서 초안(20쪽 제한과 블라인드 규칙 반영, 빈 칸은 [기재 필요]). 참여율·간접비 상한(25%)·연구수당 상한을 반영한 연차별 예산표와 산출 근거, 제출 전 점검표.

      강의평가를 반영해 강의계획서를 다시 짠다

      /syllabus · 강의계획서 작성약 20분

      자유응답의 불만이 주차별 계획과 평가 기준에 실제로 반영되는지 본다.

      과목 개요와 지난 학기 강의평가(문항별 평균 + 자유응답 15건)를 넣어, 측정 가능한 학습성과 → 역량 연계 주차별 계획 → 평가 계획·루브릭·CQI 반영 사항까지 만들어 봅니다. 응답률을 먼저 밝히고 자유응답을 주제별 건수로 묶는지, 낮은 문항(과제 양·평가 기준·실습)과 자유응답을 연결해 개선 사항 3가지를 뽑는지, 실습실 좌석 부족·선수과목 미이수 학생 같은 제약을 계획에 반영하는지가 핵심입니다.

      준비 · 샘플 파일 (skills/nxt-demo/samples/syllabus/)
        자료에 들어 있는 것
        • 3학년 전공선택 '데이터 분석 기초' 3학점 15주, 예상 45명, 실습실 40석
        • 수강생: 통계 기초 약함, 프로그래밍 경험 거의 없음, 선수과목 미이수 20%
        • 전공역량 3개 반영 비율: 문제해결 40, 데이터활용 40, 의사소통 20
        • 강의평가 31/48명 응답, 전체 3.47(학과 평균 4.12), 과제 양·평가 기준·실습 최저
        • 자유응답 15건(과제 과다, 실습 부족, 기준 불명확)과 CQI 위원회 요구 사항
        실행
        /syllabus 3학년 전공선택 '데이터 분석 기초' 3학점 15주, 전공역량 문제해결·데이터활용·의사소통 연계, 지난 학기 강의평가 반영해서 다시 짜줘. 아래 자료를 붙여 넣습니다.

        그 뒤에 course-brief.md를 먼저 붙이고, 이어서 last-eval.md를 붙여 넣으면 됩니다.

        기대 결과

        "동사+대상+조건+기준"으로 쓴 학습성과 3~5개와 Bloom 수준·역량 연계표, 응답 31명/48명 기준의 전 학기 진단 요약. 플립러닝·실습을 섞고 중간 8주·기말 15주를 박은 주차별 계획표. 루브릭이 붙은 평가 계획표와 CQI 반영 사항(개선 3가지가 어느 주차·어느 평가에 들어갔는지), 학기 말 측정 계획.
