01

무엇인가

nxt-agency는 사업단·행정·교수·학생이 자주 하는 업무를 슬래시 명령 하나로 처리하게 해 주는 AI 도우미 묶음입니다. 예를 들어 /meeting-minutes를 치고 녹취록을 붙여 넣으면 결재용 회의록이 나옵니다.

명령 하나는 여러 전문가를 순서대로 부릅니다. 사업계획서 명령은 동향 조사원, 제안서 작성가, 예산 관리자, 규정 검토관, 보고서 요약가를 차례로 거칩니다. 사용자는 순서를 몰라도 됩니다. 명령이 두세 가지만 묻고 알아서 진행합니다.

모든 안내와 결과는 한국어이고, 법령·서식·용어는 한국 대학과 공공기관 기준입니다.

15직업군 명령(스킬)
27전문가 에이전트

02

설치하기

쓰는 도구를 고르세요. 회사에서 계정을 받았다면 그 도구가 맞습니다. 세 도구 모두 설치 명령 한 줄이면 됩니다. 이 밖의 도구도 쓸 수 있으며 아래에 설명합니다.

준비물

Claude Code가 설치되어 있고 로그인이 되어 있어야 합니다. 터미널에서 claude를 쳤을 때 실행되면 됩니다.

레포를 받아 설치 명령 실행

아래 세 줄을 터미널에 붙여 넣습니다. 홈 폴더의 .claude 아래에 명령과 전문가가 들어갑니다.

확인

Claude Code를 새로 열고 /를 치면 meeting-minutes 같은 명령이 목록에 보입니다. 플러그인으로 넣었다면 nxt-agency:meeting-minutes로 보입니다.

git clone https://github.com/nxtcloud-edu/nxt-agency.git
cd nxt-agency
./scripts/install.sh --tool claude-code
내 직업군 것만 넣으려면 ./scripts/install.sh --role admin 처럼 씁니다. 직업군은 네 가지입니다: project(사업단), admin(행정), research(교수·연구자), student(학생). 고른 직업군의 명령과 거기에 필요한 전문가만 설치됩니다.

또는 플러그인으로 (레포를 받지 않고)

Claude Code 안에서 아래 두 줄을 차례로 치면 명령과 전문가가 한 번에 들어가고, 업데이트도 Claude Code가 알아서 합니다. 대신 이름 앞에 nxt-agency:가 붙어 /nxt-agency:meeting-minutes처럼 부릅니다. "회의록 만들어줘"처럼 말로 하면 접두어 없이도 알아서 찾습니다.

/plugin marketplace add nxtcloud-edu/nxt-agency
/plugin install nxt-agency@nxt-agency
설치 스크립트와 플러그인을 같이 쓰면 같은 명령이 두 벌 보입니다. 한쪽만 쓰세요. 플러그인을 지우려면 /plugin uninstall nxt-agency@nxt-agency.

준비물

Codex CLI 또는 Codex 앱이 설치되어 있고 로그인이 되어 있어야 합니다. 홈 폴더에 .codex 폴더가 있으면 준비된 것입니다.

설치 명령 실행

같은 설치 스크립트에 --tool codex를 붙입니다. 명령은 ~/.codex/skills에 그대로 들어가고, 전문가는 Codex 커스텀 에이전트 형식(TOML)으로 바뀌어 ~/.codex/agents에 들어갑니다.

확인

Codex에서 /skills를 치면 명령 목록이 보이고, $meeting-minutes처럼 $를 붙여 부릅니다. 전문가를 서브에이전트로 쓰려면 Codex 설정에서 멀티에이전트 기능을 켜야 합니다.

git clone https://github.com/nxtcloud-edu/nxt-agency.git
cd nxt-agency
./scripts/install.sh --tool codex
Codex는 명령을 /가 아니라 $로 부릅니다. /meeting-minutes 대신 $meeting-minutes라고 치세요.

준비물

회사에서 받은 Kiro 계정으로 Kiro IDE 또는 Kiro CLI에 로그인되어 있어야 합니다. 홈 폴더에 .kiro 폴더가 생겨 있으면 준비된 것입니다.

설치 명령 실행

같은 설치 스크립트에 --tool kiro를 붙입니다. 명령은 그대로 들어가고, 전문가는 Kiro의 커스텀 에이전트 형식으로 바뀌어 들어갑니다.

확인

Kiro 채팅에서 /meeting-minutes를 치면 스킬이 실행됩니다. 전문가는 /agent로 전환해 고를 수 있습니다.

git clone https://github.com/nxtcloud-edu/nxt-agency.git
cd nxt-agency
./scripts/install.sh --tool kiro
Kiro는 버전에 따라 에이전트 형식이 바뀐 적이 있습니다. 명령은 보이는데 전문가가 안 보이면 담당자에게 알려 주세요. 명령만으로도 업무는 끝낼 수 있습니다.

그 밖의 도구. 명령은 Agent Skills 표준 형식이라 이를 지원하는 다른 도구에서도 쓸 수 있습니다. 예를 들어 claude.ai 웹은 설정 → 기능 → 스킬에서 zip을 올리면 되고, 다른 CLI는 스킬 폴더를 복사하면 됩니다. zip은 레포에서 ./scripts/package-skills.sh로 만듭니다. 명령 안에 전문가의 규칙과 서식이 들어 있어 전문가 없이도 같은 결과를 냅니다.

03

샘플로 체험하기 · 데모 핸즈온

자기 자료를 넣기 부담스럽거나 무엇을 넣어야 할지 모르겠다면 여기서 시작하세요. 15분이면 명령 하나를 끝까지 경험할 수 있습니다. 모든 샘플은 가상 대학(한빛대학교)과 가상 인물의 자료입니다. 체크한 항목은 이 브라우저에 저장됩니다.

준비 확인 1분

/(Codex는 $)를 쳤을 때 목록에 nxt-demo가 보이면 준비된 것입니다. 안 보이면 설치하기로.

체험 명령 실행 2분

아래 한 줄을 치면 직업군별로 할 수 있는 일을 표로 보여 주고 하나를 고르게 합니다. 처음에는 회의록을 권합니다. 결과가 가장 직관적입니다.

/nxt-demo 회의록 샘플로 해 보자

끝까지 진행하고 함정을 확인 5분

"시작할까요?"에 "네"라고 하면 회의록 정리원의 절차대로 진행합니다. 결과 아래 "이렇게 처리했습니다" 설명과 함께 다음 세 가지를 찾아보세요.

"내 자료로 하려면" 읽기 2분

결과 끝에 실제로 칠 명령, 준비할 자료, 지워야 할 개인정보가 세 줄로 나옵니다. 이것이 다음에 내 녹취록으로 할 때의 출발점입니다.

다른 샘플 하나 더 5분

이번엔 내 직업군의 것으로. "다른 것도 해 볼까요?"에 명령 이름을 답하면 됩니다. 아래 표에서 고르세요.

더 깊이. 직업군별로 실제 업무 순서대로 명령 3~4개를 이어서 해 보는 핸즈온 시나리오가 따로 있습니다. 페르소나와 상황이 주어지고, 실습마다 확인 항목과 기대 결과가 있습니다.

사업단집행 점검 → 행사 준비 → 성과보고 → 차년도 계획 · 90분 행정회의록 → 문의 답변 → 동의서 → 처장 보고 · 60분 교수·연구자선행연구 → 연구계획서 → 강의계획서 · 75분 학생학기 계획 → 캡스톤 → 자기소개서 · 60분

샘플에 넣어 둔 함정. 담당자가 정해지지 않은 조치사항, 학부모가 자녀 성적을 묻는 문의, 목표에 못 미친 지표, 부풀리고 싶은 경험 같은 것들입니다. 명령이 이런 부분을 어떻게 처리하는지 보는 것이 체험의 핵심입니다.

명령샘플 데이터들어 있는 함정
/meeting-minutes운영위원회 녹취록결정과 논의가 섞임, 담당·기한 없는 조치사항, 일시·장소 누락
/report-summary중간평가 자체보고서 요약본수치가 많아 무엇을 남길지 골라야 함
/inquiry-reply문의·민원 4건학부모의 자녀 성적 문의, 감정적 공정성 민원
/consent-form재학생 설문 계획불필요한 수집 항목, 보관 기간 미정, 외부 제공
/business-plan공고 요강 발췌 + 사업단 현황평가지표에 맞춰 강점·약점을 배치해야 함
/performance-reportKPI 실적표 + 만족도미달 지표의 원인과 개선 방향
/event-prep성과발표회 개요담당자·예산이 미정인 항목
/budget-check세목별 집행 현황집행 부진과 과집행, 미증빙 카드 건
/literature-review주제 메모 + 가상 문헌 10편설계 수준이 제각각, 같은 데이터를 재사용한 논문
/research-proposal공고 발췌 + 연구자 프로필배점표에 맞춘 계획서 구성
/syllabus과목 개요 + 지난 강의평가강의평가 불만을 CQI로 반영
/cover-letter공공기관 공고 + 경험 목록"부풀려도 될까?" 메모가 달린 경험
/semester-plan학생 상황 메모목표 대비 시간이 부족한 시간표
/capstone아이디어 메모기능 12개, 발표 2주 전, 코드 없음
04

첫 명령 실행

가장 많이 쓰는 회의록 명령으로 흐름을 보겠습니다. 명령 뒤에 상황을 한 줄 적고, 그다음 자료를 붙여 넣으면 됩니다. 단계가 끝날 때마다 한 번 확인을 묻고, "끝까지"라고 하면 멈추지 않고 진행합니다.

Claude Code · 예시 대화
나
/meeting-minutes 사업단 운영위원회 회의록, 결재용
AI
회의록을 만들기 전에 두 가지만 확인하겠습니다. 1. 회의 자료(녹취록·메모)를 붙여 넣어 주세요. 2. 일시·장소·참석자 중 자료에 없는 것이 있으면 알려 주세요. (없으면 "확인 필요"로 표시합니다)
나
(녹취록 붙여 넣기) 일시는 9월 12일 14시, 회의실 301호.
AI
1단계. 자료에서 안건 3건, 결정사항 4건, 조치사항 5건을 찾았습니다. 담당자가 없는 조치사항 1건은 "담당 미정"으로 두었습니다. 여기까지 확인하시겠어요? 아니면 끝까지 진행할까요?
나
끝까지
AI
2단계. 회의 개요 · 안건 · 논의내용 · 결정사항 · 조치사항(담당/기한) · 미결사항 순서로 회의록을 정리했습니다. 3단계. 결재란이 포함된 DOCX 파일로 저장했습니다: 운영위원회_회의록_0912.docx
무엇을 써야 할지 모르겠으면 안내 데스크에게 물어보세요. 상황을 말하면 맞는 명령과 뒤에 붙일 말까지 만들어 줍니다.
안내 데스크, 나는 사업단 행정 담당인데 연차평가 성과보고서를 처음 써야 해. 어디부터 시작하면 돼?
05

내 일에 맞는 명령

직업군을 고르면 그 일에 맞는 명령이 나옵니다. 예시 문장은 복사해서 그대로 쓰고, 괄호 안 내용만 내 상황으로 바꾸면 됩니다.

/budget-check

예산 집행 점검

사업비 집행 현황을 세목별 집행률 점검표 → 부정 집행 위험·규정 점검 → 사업단장 보고용 요약 순서로 점검한다.

세목별 집행률 점검표 → 부정 집행 위험·규정 점검 → 보고용 요약
함께 일하는 전문가: 예산·집행 관리자 · 규정·법령 검토관 · 보고서 요약가
이렇게 시작하세요
/budget-check LINC 3.0 3차년도 8월 말 집행 현황, 세목별 엑셀 첨부
/budget-check RIS 사업 연차 종료 3개월 전 정산 준비 점검
/business-plan

사업계획서 작성

사업단·기관의 연차 사업계획서 초안을 동향·근거 조사 → 계획서 초안 → 세목별 예산표 → 규정 점검 → 사업단장 보고용 1페이지 순서로 만든다.

동향·근거 조사 → 계획서 초안 → 세목별 예산표 → 규정 점검 → 사업단장 보고용 1페이지
함께 일하는 전문가: 연구·산업 동향 조사원 · 연구과제·사업 제안서 작성가 · 예산·집행 관리자 · 규정·법령 검토관 · 보고서 요약가

/event-prep

행사 준비

사업단 행사(성과발표회·경진대회·특강·포럼·워크숍) 준비를 준비 일정표 → 모집 공고문·카드뉴스 문안 → 보도자료 → 결과 회의록 서식 순서로 만든다.

준비 일정표(과업·담당·기한) → 모집 공고문·카드뉴스 문안 → 보도자료 → 결과 회의록 서식
함께 일하는 전문가: 사업 관리자 · 홍보 콘텐츠 제작자 · 홍보·보도자료 담당 · 회의록 정리원
이렇게 시작하세요
/event-prep LINC 3.0 캡스톤디자인 성과발표회, 11월 20일, 참여 팀 20개
/event-prep 산학협력 창업 경진대회 모집, 3·4학년 대상, 인스타 카드뉴스 필요
/performance-report

성과보고서 작성

KPI 달성률 표 → 만족도·정성 성과 → 개조식 요약 → DOCX/PPTX 파일
함께 일하는 전문가: 성과 분석가 · 설문·의견 분석가 · 보고서 요약가 · 문서 생성기

07

자주 묻는 질문

한글로 /회의록이라고 치면 안 되나요?

안 됩니다. Claude Code, Codex, Kiro 모두 명령 이름은 영문만 허용합니다. 대신 /(Codex는 $)만 치면 목록이 뜨고, "회의록 만들어줘"처럼 말로 해도 맞는 스킬을 찾아 씁니다.

결과에 나온 법령·수치를 그대로 써도 되나요?

확인 후에 쓰세요. 전문가들은 법령 조항 번호처럼 확실하지 않은 사실은 쓰지 않도록 만들어져 있지만, AI는 틀릴 수 있습니다. 규정·법령 검토관과 개인정보보호 담당관의 결과는 법률 자문이 아니며, 최종 판단은 법무·감사 부서와 확인해야 합니다.

학생 명단이나 연락처를 붙여 넣어도 되나요?

가급적 넣지 마세요. 이름·학번·연락처·주민번호는 지운 뒤 붙여 넣고, 필요하면 "A학생"처럼 바꿔 쓰세요. 민원 답변 명령은 답변에 개인정보가 들어가지 않도록 점검하지만, 입력 단계에서 빼는 것이 가장 안전합니다.

한글(HWP) 파일로 받을 수 있나요?

바로는 어렵습니다. 문서 생성기는 DOCX·PPTX·XLSX·PDF를 만듭니다. DOCX로 받은 뒤 한컴오피스에서 열어 HWP로 저장하면 됩니다. 서식이 어긋나면 표 부분만 다시 잡아 주세요.

다른 도구에서 쓰는데 "전문가가 없다"고 나옵니다.

정상입니다. claude.ai 웹처럼 전문가 에이전트를 따로 설치할 수 없는 도구에서는 각 명령이 전문가의 규칙과 서식을 안에 품고 혼자 동작합니다. 결과 품질은 같습니다.

명령을 몇 개만 골라 쓰고 싶어요.

설치할 때 --role student(직업군) 또는 --skill cover-letter(명령 하나)를 붙이면 그것과 거기에 필요한 전문가만 들어갑니다. 웹은 zip을 골라 올리면 됩니다.

문제 해결

명령이 목록에 안 보여요

도구를 완전히 닫고 다시 여세요. 그래도 없으면 설치 위치를 확인합니다: Claude Code는 ~/.claude/skills, Codex는 ~/.codex/skills, Kiro는 ~/.kiro/skills 아래에 명령 이름 폴더가 있어야 합니다. 플러그인으로 넣었다면 /plugin list에 nxt-agency가 있는지, 명령은 /nxt-agency:로 시작하는지 확인합니다.

설치 스크립트가 "선택된 항목이 없습니다"라고 해요

--role이나 --skill 뒤의 이름이 틀린 경우입니다. ./scripts/install.sh --list로 정확한 이름을 확인하세요. 직업군 값은 project admin research student 네 가지입니다.

최신 버전으로 바꾸고 싶어요

레포 폴더에서 git pull 후 설치 명령을 다시 실행하면 덮어씁니다. 지우려면 ./scripts/install.sh --uninstall. 이 레포에서 설치한 것만 지우고 다른 파일은 건드리지 않습니다.

결과가 이상해요

대부분 입력 자료가 부족한 경우입니다. 명령이 물어본 질문에 답을 채우고, 자료를 더 붙여 넣어 보세요. 그래도 이상하면 담당자에게 어떤 명령에 무엇을 넣었는지 알려 주세요.
