# /literature-review 체험 — 석사논문 2장 선행연구 정리

**이 샘플로 해 볼 수 있는 것**: 지도교수 코멘트가 붙은 주제 메모와 후보 문헌 10편을 넣어, 검색 전략서 → 근거 수준이 매겨진 정리표 → 연구 공백·설계 시사점까지 한 번에 뽑아 봅니다. 같은 데이터를 재사용한 논문 2편, 종단 연구와 횡단 연구의 불일치, 학위논문·개념이 다른 논문의 포함 여부를 스킬이 어떻게 처리하는지가 핵심입니다.

**내용**:
- 석사 2학기 학생의 주제 메모: 진로결정 자기효능감 → 취업준비행동
- 연구질문 초안 3개(예측, 학년 차이, 진로장벽 매개)와 지도교수 코멘트 5개
- 가상 후보 문헌 10편: 메타분석 1, 종단 1, 질적 1, 준실험 1, 학위논문 1, 횡단 5
- 각 문헌의 설계·표본·측정·핵심 결과(β, r, CI) 정리
- 1차 선별 후 남은 고민 5가지(척도 불일치, 횡단 자료 해석 등)

**파일**:
- topic-brief.md — 석사 2학기 학생의 주제 메모. 연구질문 초안 3개, 헷갈리는 점, 지도교수 면담 코멘트, 다음 주 할 일
- candidate-sources.md — 1차 선별한 가상 문헌 10편(메타분석 1, 종단 1, 질적 1, 준실험 1, 학위논문 1, 횡단 설문 다수). 상단에 "가상 문헌" 표기

**이렇게 시작하세요**
```
/literature-review 대학생 진로결정 자기효능감과 취업준비행동, 석사논문 2장, 국내외 최근 10년. 아래 자료를 붙여 넣습니다.
```
그 뒤에 topic-brief.md 전체를 먼저 붙이고, 이어서 candidate-sources.md 전체를 붙여 넣으면 됩니다.

**기대 결과**: 대상/비교/결과로 구조화된 연구질문과 포함·배제 기준이 담긴 검색 전략서. 10편의 근거 등급·방법의 질·독립성·약한 고리를 매긴 정리표(1번과 3번은 같은 데이터로 표시). "잘 확립됨 / 논쟁 중 / 단일 연구뿐 / 근거 공백"으로 나눈 종합 지도와, 종단 연구의 역인과 결과를 반영한 설계 시사점.
