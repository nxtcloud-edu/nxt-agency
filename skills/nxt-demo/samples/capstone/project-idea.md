# 캡스톤 아이디어 메모: AI 강의노트 요약 서비스 (가칭 "노트짱")

- 한빛대학교 컴퓨터공학과 4학년 캡스톤디자인 1, 팀 4명
- 지도교수: 박지훈 교수
- 작성: 팀장 이도윤, 2차 팀 회의 직후
- **중간 발표: 2주 뒤 (D-14), 15분 발표 + 시연**. 최종 발표는 12월.
- 현재 상태: **코드 한 줄도 없음.** 노션에 아이디어 페이지만 있음. 깃허브 저장소도 아직 안 만듦.

## 1. 한 줄 설명 (아직 합의 안 됨)

- 이도윤 버전: "강의 녹음이나 슬라이드를 올리면 AI가 요약 노트를 만들어 주는 서비스"
- 강태우 버전: "대학생을 위한 올인원 AI 학습 플랫폼"
- 교수님: "한 문장으로 누가 왜 쓰는지 말해 봐라. '올인원'은 한 문장이 아니다."

## 2. 하고 싶은 기능 (2차 회의에서 나온 것 전부, 12개)

1. 강의 녹음 파일(mp3/m4a) 업로드 → 음성 인식 → 텍스트 변환
2. 변환된 텍스트를 AI로 요약 (핵심 개념, 키워드, 3줄 요약)
3. 강의 슬라이드(PDF) 업로드 → 텍스트 추출 → 요약과 병합
4. 요약 노트를 마크다운으로 편집·저장
5. 요약에서 자동으로 **퀴즈 생성** (객관식 5문항)
6. 플래시카드 만들기 + 간격 반복 복습 알림
7. 같은 수업 듣는 친구와 노트 공유·공동 편집 (실시간)
8. 강의별·주차별 노트 정리 (폴더/태그)
9. 학교 LMS 연동해서 강의 일정 자동 불러오기
10. 모바일 앱 (iOS·Android)
11. 교수님용 대시보드 (학생들이 어디서 헷갈리는지 통계)
12. 유료 구독 결제 (프리미엄: 무제한 요약)

- 강태우: 5, 6, 7 없으면 "그냥 요약기"라서 차별성이 없다고 함.
- 한소희: 10(모바일 앱)은 이번 학기에 절대 못 한다고 함.
- 정민재: 9(LMS 연동)는 학교 API가 없어서 불가능할 것 같다고 함. 확인은 안 해 봄.
- 이도윤: 뭘 빼야 할지 모르겠음. 다 좋아 보임.

## 3. 팀원 역량 (자기 평가)

| 이름 | 할 수 있는 것 | 못 하는 것 / 걱정 | 이번 학기 상황 |
|---|---|---|---|
| 이도윤 (팀장) | Python 중급, Flask로 수업 과제 해 봄, Git 기본 | 프론트엔드 거의 못 함, 배포 경험 없음 | 취업 준비 병행, 주 10시간 가능 |
| 강태우 | React 기초(수업 프로젝트 1회), Figma로 화면 그릴 수 있음 | 백엔드·DB 모름 | 주 15시간 가능, 아이디어 많음 |
| 한소희 | Python, 머신러닝 수업 A, OpenAI API 써 본 적 있음(개인 토이) | 웹 개발 경험 없음, Git 충돌 나면 무서움 | 대학원 준비, 주 8시간 |
| 정민재 | Java/Spring 수업 들었음, SQL 가능 | Python 안 써 봄, 발표 싫어함 | 주 12시간, 다른 팀플 2개 |

- 스택 안 정해짐. 이도윤은 Flask, 정민재는 Spring, 강태우는 "요즘은 Next.js 아니냐"고 함.
- 음성 인식은 Whisper API 쓰면 될 것 같다고 한소희가 말했는데 비용은 안 계산해 봄.
- 서버 비용: 팀 예산 없음. 학과에서 캡스톤 지원금 20만 원 나온다고 들었음(확인 필요).

## 4. 지도교수 요구사항 (1차 면담 메모)

- "중간 발표에서는 **핵심 흐름 하나가 실제로 돌아가는 것**을 보여라. 슬라이드만 있으면 감점."
- "기능 12개 중에 3개만 골라라. 나머지는 '향후 계획' 슬라이드 한 장에 넣어라."
- "누가 쓰는지 말할 수 있어야 한다. 시연 전에 같은 과 학생 최소 5명한테 써 보게 하고 반응을 가져와라."
- "강의 녹음 파일은 **교수 저작물**이자 수업 중 발언이 담긴 것이니, 업로드 동의와 저장 기간을 처음부터 설계에 넣어라. 개인정보 처리 방침 없이 발표하면 질문 받을 것."
- "API 키 깃허브에 올리는 팀이 매년 나온다. 그러면 최종 심사에서 0점 준다."
- "마이크로서비스 하겠다는 팀은 말려라. 너희는 4명이다."
- 최종 심사 평가 항목(학과 공지): 문제 정의 20 / 구현 완성도 30 / 기술적 타당성 20 / 사용자 검증 15 / 발표·문서 15
