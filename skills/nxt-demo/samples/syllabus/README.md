**이 샘플로 해 볼 수 있는 것**: 과목 개요와 지난 학기 강의평가(문항별 평균 + 자유응답 15건)를 넣어, 측정 가능한 학습성과 → 역량 연계 주차별 계획 → 평가 계획·루브릭·CQI 반영 사항까지 만들어 봅니다. 응답률을 먼저 밝히고 자유응답을 주제별 건수로 묶는지, 낮은 문항(과제 양·평가 기준·실습)과 자유응답을 연결해 개선 사항 3가지를 뽑는지, 실습실 좌석 부족·선수과목 미이수 학생 같은 제약을 계획에 반영하는지가 핵심입니다.

**내용**:
- 3학년 전공선택 '데이터 분석 기초' 3학점 15주, 예상 45명, 실습실 40석
