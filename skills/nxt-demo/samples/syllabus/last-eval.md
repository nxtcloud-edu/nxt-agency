# 지난 학기 강의평가 결과: 데이터 분석 기초 (MIS3204)

- 학기: 직전 2학기 · 담당: 최유나 교수
- 수강 인원 48명 / **응답 31명 (응답률 64.6%)**
- 학교 강의평가는 5점 척도(1 전혀 그렇지 않다 ~ 5 매우 그렇다). 학과 전공과목 평균은 4.12.
- 자유응답은 원문 그대로 옮김. 학번·이름은 시스템에서 이미 제거됨.

## 2. 자유응답 (15건, 원문)

1. 과제가 매주 나오는데 하나에 4~5시간 걸립니다. 다른 전공 과목 과제랑 겹치면 잠을 못 잡니다. 과제 수를 줄이거나 격주로 해 주세요.

2. 교수님은 정말 열심히 하시고 질문하면 잘 답해 주십니다. 그런데 수업이 통계 이론 위주라서 "데이터 분석"이라는 이름과 다르게 느껴졌습니다. 직접 데이터를 만져 보는 시간이 너무 적었어요.

3. 과제 점수가 왜 그렇게 나왔는지 모르겠습니다. 어떤 기준으로 채점하는지 처음부터 알려 주셨으면 좋겠습니다. 친구랑 비슷하게 했는데 점수가 달랐어요.

4. 3주 동안 엑셀 하다가 갑자기 파이썬으로 바뀌어서 그때부터 따라가기 힘들었습니다. 파이썬 처음 배우는 사람 기준으로 한 주 정도는 설치랑 기본 문법을 해 줬으면.

5. 팀 프로젝트에서 한 명이 거의 안 했는데 점수는 똑같이 받았습니다. 이게 제일 불공평했습니다.

6. 파이썬 교재 사라고 하셨는데 거의 안 썼어요. 2만 원 넘게 주고 샀는데 아깝습니다.

7. 좋은 수업이었습니다. 다만 노트북이 없는 사람은 실습을 아예 못 했어요. 실습실에서 하면 좋겠습니다.

8. 경영통계 안 듣고 들었는데 처음부터 p값, 신뢰구간 이런 게 나와서 뭔지 몰랐습니다. 2학년도 들을 수 있다고 해서 들었는데 후회했습니다. 선수과목 안 들었으면 어떻게 하라는 안내라도 있었으면.

9. 중간고사가 수업에서 다룬 것보다 어려웠어요. 시험 범위와 유형을 미리 알려 주셨으면 좋겠습니다.

10. 매주 과제, 팀플, 중간, 기말 다 있어서 3학점짜리 수업이 6학점처럼 느껴졌습니다. 다 필요한 건 알겠는데 좀 줄여 주세요.

11. 실무에서 데이터 분석을 어떻게 쓰는지 사례가 더 있었으면 좋겠어요. 통계 공식은 알겠는데 회사에서 이걸 어디에 쓰는지 감이 안 왔습니다.

12. 교수님 설명은 좋았지만 수업 시간 3시간 연강이 너무 길었습니다. 중간에 쉬는 시간이 거의 없었어요.

13. 과제 피드백이 점수만 있고 뭘 틀렸는지 코멘트가 없어서 다음 과제에서 뭘 고쳐야 하는지 몰랐습니다.

14. 별 문제 없었습니다. 잘 들었습니다.

15. 강의계획서에는 실습 1시간이라고 되어 있었는데 실제로는 거의 강의였습니다. 계획서대로 해 주세요.

## 3. 학과 CQI 위원회 메모 (강의평가 결과에 붙은 코멘트)

- 학과 평균 대비 0.65점 낮음. 특히 Q6(과제 양), Q8(평가 기준), Q10(실습)이 3.1 미만.
- 교수 준비·성실성(Q4, Q5)은 학과 평균 이상 → 교수 태도 문제가 아니라 **설계 문제**로 판단.
- 다음 학기 강의계획서에 개선 사항 3가지 이상을 명시하고, 역량-학습성과-평가 연결표를 첨부할 것.
- 응답률 64.6%는 유효하나, 자유응답 15건 중 강한 표현이 몇 건 있음 — 건수 기준으로 해석할 것.
