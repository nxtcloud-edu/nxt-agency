# 🎪 행사 준비

사업단이 여는 성과발표회, 경진대회, 특강, 포럼, 워크숍 같은 행사를 준비할 때 필요한 문서를 한 번에 만들어 드립니다. 누가 언제까지 무엇을 하는지 적은 준비 일정표, 참가자를 모으는 공고문과 카드뉴스 문안, 언론에 보낼 보도자료, 행사 뒤 결과를 정리할 회의록 서식까지 나옵니다. 행사를 처음 맡은 사업단 직원도 행사명·날짜·대상만 알려 주면 시작할 수 있습니다.

## 시작할 때 물어볼 것
최대 3개. 사용자가 이미 말했으면 묻지 않는다. 답이 없으면 괄호 안 기본값으로 진행한다.
1. 어떤 행사인가요? 행사명, 일시, 장소, 대상(학생·기업·교수·지역주민), 예상 인원을 알려 주세요. (기본값: 알려 준 것만 쓰고 나머지는 "[입력 필요]"로 남김)
2. 사업계획서에 이 행사가 어떻게 적혀 있고, 어떤 성과지표(KPI)에 연결되나요? (기본값: 연계 지표는 "[계획서 확인 필요]"로 표시)
3. 홍보 채널은 무엇인가요? 학교 홈페이지 공고, 인스타그램, 언론 배포 중 필요한 것을 알려 주세요. (기본값: 공식 공고문 + 인스타그램 카드뉴스 + 보도자료 모두 작성)

각 단계가 끝나면 "여기까지 확인하시겠어요, 계속 진행할까요?"를 한 번만 묻고, 사용자가 "끝까지 진행"이라고 하면 다시 묻지 않는다.

## 진행 단계

### 1단계. 준비 일정표(과업·담당·기한) — 전문가: `program-manager`(사업 관리자)
- **위임**: `program-manager` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 사업계획서에 명시되지 않은 "고급·대규모·전국 최초" 프로그램을 덧붙이지 않는다. 기본에 충실한 실행이 정상이다.
  - 각 과업은 담당자 한 명이 한 주 안에 착수해 마무리할 수 있는 크기로 쪼갠다.
  - 과업마다 완료 기준(무엇이 나오면 끝인가)과 증빙(참석자 명단, 사진, 결과보고서, 지출 증빙)을 적는다.
  - 행사일에서 역산해 마감을 잡는다. 보도자료는 행사 2주 전 사전 안내, 당일 결과 배포를 일정에 넣는다.
  - 어떤 KPI에 기여하는지 표시하고, 사업비 집행(회의비·홍보비·강사료) 시점을 함께 적는다.
- **이 단계 산출물**: 행사 준비 과업표

  | 번호 | 과업 | 내용·완료 기준 | 담당 | 마감 | 선행 과업 | 연계 지표 | 증빙 |
  |---|---|---|---|---|---|---|---|
  | 1 | 장소·일정 확정 | 대관 확정서 수령 | ○○팀 | D-30 | - | - | 대관 확인서 |
  | 2 | 모집 공고 게시 | 홈페이지·SNS 게시 | 홍보 담당 | D-21 | 1 | 참여 학생 수 | 공고 캡처 |
  | 3 | 보도자료 사전 배포 | 대학 홍보팀 검수 후 배포 | 홍보 담당 | D-14 | 1 | - | 배포 기록 |
  | … | 참석자 명단·사진·결과보고 | | | D+3 | | | |

  점검 항목: 모든 과업에 담당·마감·완료 기준·증빙이 있는가 / 예산 집행 시점이 일정과 맞는가 / 개인정보 수집 동의 절차가 들어 있는가
- **다음 단계로 넘길 것**: 모집 기간·신청 방법·선발 일정, 행사 핵심 정보(일시·장소·대상·혜택·문의처)

### 2단계. 모집 공고문·카드뉴스 문안 — 전문가: `content-creator`(홍보 콘텐츠 제작자)
- **위임**: `content-creator` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 첫 문장은 "기관이 무엇을 했다"가 아니라 "독자에게 무엇이 좋은가"로 시작한다.
  - 모집 공고에는 대상·기간·방법·혜택·문의처·유의사항이 빠지지 않아야 하고, 공식 공고문과 카드뉴스 내용이 어긋나지 않게 한다.
  - 카드뉴스는 장당 한 메시지, 행동 유도는 게시글 하나에 한 가지(신청)만 둔다.
  - 사업 용어(산학협력, 캡스톤디자인, 리빙랩 등)는 첫 등장 시 한 줄 설명을 붙인다.
  - 사진·실명·인터뷰는 사전 동의가 있는 것만 쓰고, 사업명·기관명·주무부처 표기 규정을 지킨다.
- **이 단계 산출물**:
  - 공식 공고문(개조식): 1.목적 → 2.모집 대상 → 3.모집 인원 → 4.활동 기간 및 내용 → 5.지원 사항 → 6.신청 방법 및 기간 → 7.선발 방법 및 일정 → 8.유의 사항(개인정보 수집·이용 동의 포함) → 9.문의
  - 학생용 3줄 요약: ✔ 누가 / ✔ 무엇을 / ✔ 언제까지 + 한 줄 후킹 + 신청 링크
  - 카드뉴스 9장 문안: [표지] 후킹 문구 15자 내외 → [2장] 대상 → [3장] 무엇을 하는지 → [4장] 혜택 → [5장] 참여자 한 줄 후기(동의 확보) → [6장] 일정 → [7장] 신청 방법 3단계 → [8장] 자주 묻는 질문 2개 → [9장] 행동 유도 + 문의처 + 주관·후원 표기
  - 캡션: 첫 줄 후킹 → 핵심 3줄 → 신청 링크 → 해시태그 10개 이내
- **다음 단계로 넘길 것**: 확정된 행사 핵심 정보와 표기 규정에 맞는 사업명·기관명, 강조할 수치(참여 기업 수, 상금 규모 등)

### 3단계. 보도자료 — 전문가: `pr-manager`(홍보·보도자료 담당)
- **위임**: `pr-manager` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 리드 두 문장 안에 누가·무엇을·언제·어디서·왜를 담는다. 기관명보다 뉴스 가치를 먼저 쓴다.
  - 제목은 능동형 25자 내외. "국내 최초", "세계 최고" 같은 표현은 근거 자료가 있을 때만 쓴다.
  - 핵심 메시지는 3개까지. 사업단장 인용문은 리드 반복이 아니라 관점과 의지를 사람의 말투로 쓴다.
  - 대학 명의 보도자료는 대학 홍보팀 검수·배포 절차를 따르고, 외부 발표 전 구성원·참여교수에게 먼저 공유한다.
  - 참여 학생·기업 정보는 동의를 받은 것만 쓴다.
- **이 단계 산출물**: 보도자료(한국 언론 서식) 2종 — 사전 안내용(행사 2주 전), 결과 보도용(행사 당일)
  ```
  보도자료
  [기관 로고]   보도 일시: 즉시 보도 가능 (또는 ○월 ○일 ○시 이후)
                담당: ○○사업단 ○○팀 [입력 필요] (☎, 이메일)   사진 있음/없음   총 ○쪽
  [제목 — 능동형, 뉴스 가치 중심, 25자 내외]
  [부제 — 맥락이나 핵심 수치 한 문장]
  □ 리드 / □ 배경과 의미 / □ 세부 내용(규모·참여 기관·구성·수치)
  □ 사업단장 인용문 / □ 협력기관·수혜자 인용문 / □ 향후 계획·신청 방법·문의처
  붙임 1. 행사 사진 ○매  붙임 2. 사업 개요 1쪽  붙임 3. 참고자료
  [기관 소개 — 2~3문장]
  ```
- **다음 단계로 넘길 것**: 행사 후 결과 보도자료에 채울 실적 항목(참석 인원, 수상 팀, 참여 기업 수)

### 4단계. 결과 회의록 서식 — 전문가: `meeting-minutes`(회의록 정리원)
- **위임**: `meeting-minutes` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 추출하지 창작하지 않는다. 자료에 없는 결정은 결정사항에 넣지 않고, 담당이 불분명하면 "[담당: 미지정]"으로 남긴다.
  - 결정과 논의는 다르다. "이월 방안을 논의함"은 논의, "○월 ○일까지 제출하기로 함"이 결정이다.
  - 한 사람의 발언을 회의체의 결정으로 격상하지 않는다.
  - 여섯 항목(회의 개요·안건·논의내용·결정사항·조치사항·미결사항)을 항상 출력하고, 내용이 없으면 "[기록 없음]"으로 채운다.
  - 결재용이면 상단에 "결재: 담당 / 팀장 / 부서장" 표시 줄을 추가한다. 서명·직인은 만들지 않는다.
- **이 단계 산출물**: 행사 결과 회의록 서식(행사 뒤 결과 회의 메모를 붙이면 채워 준다)
  ```
  # [행사명] 결과 회의 회의록
  ## 1. 회의 개요  - 일시 / 장소 / 참석자(총 N명) / 불참자 / 작성자
  ## 2. 안건  1. 행사 결과 보고(참석 인원·만족도·예산 집행)  2. 잘된 점·개선점  3. 후속 조치
  ## 3. 논의내용  - [발언자 또는 부서]: [주요 의견 한 문장]
  ## 4. 결정사항  1. [완결된 한 문장]
  ## 5. 조치사항  | 번호 | 조치 내용 | 담당 | 기한 | 비고 |
  ## 6. 미결사항  - [제기됐으나 결론 나지 않은 쟁점]
  ```
- **다음 단계로 넘길 것**: 없음(최종 단계)

## 최종 산출물
- 행사 준비 과업표(과업·담당·마감·증빙·연계 지표)
- 공식 모집 공고문 + 학생용 3줄 요약 + 카드뉴스 9장 문안과 캡션
- 보도자료 2종(사전 안내용, 결과 보도용)
- 행사 결과 회의록 서식(결재용 표시 줄 포함)
- 파일이 필요하면 공고문·회의록은 DOCX(python-docx), 과업표는 XLSX(openpyxl)로 만들고, HWP는 DOCX를 한컴오피스에서 변환하도록 안내한다.

## 하지 말 것
- 없는 사실·수치·법령 조항 번호를 지어내지 않는다. (공통)
- 개인정보(이름·학번·연락처)를 예시나 결과에 넣지 않는다. (공통)
- 동의를 받지 않은 참여자 사진·실명·후기를 홍보물이나 보도자료에 쓰지 않는다.
- 공식 공고문과 카드뉴스·보도자료의 날짜·대상·혜택이 서로 다르게 적히지 않게 한다.
- 계획서에 없는 행사 규모나 "국내 최초" 같은 근거 없는 최상급 표현을 쓰지 않는다.
