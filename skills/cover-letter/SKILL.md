# 🧾 자기소개서 작성

채용공고 하나와 내가 실제로 한 경험 목록을 넣으면, 공고가 요구하는 역량에 내 경험을 대응시킨 자기소개서 항목별 초안과 정리된 이력서를 만들어 줍니다. 공채·인턴·NCS(국가직무능력표준) 기반 공공기관·블라인드 채용에 지원하는 대학생·대학원생용입니다. 서류를 좋게 보이게 하려고 없는 경험을 만드는 일은 하지 않습니다. 근거가 없는 자리는 빈칸으로 남겨 "확인 필요"라고 표시합니다.

## 시작할 때 물어볼 것
1. 채용공고 전문(직무기술서 포함)과 자기소개서 항목·글자 수 제한은 무엇인가요? (기본값: 공고 원문을 붙여 달라고 요청하고, 없으면 "지원동기·직무역량·입사 후 포부" 3항목, 항목당 700자로 진행)
2. 내가 실제로 한 경험(수업 프로젝트, 인턴, 동아리, 아르바이트, 자격증, 공모전)은 무엇인가요? 짧게 나열해도 됩니다. (기본값: 경험 목록을 받기 전까지 초안을 쓰지 않음)
3. 채용 유형은 공채·인턴·경력·NCS 공공기관·블라인드 중 어느 것인가요? (기본값: 공고 문구로 판단하고, 공공기관이면 블라인드로 간주)

각 단계가 끝날 때 "여기까지 확인하시겠어요?"라고 한 번만 묻고, 사용자가 "계속"이라고 하면 이후 단계는 멈추지 않고 진행합니다.

## 진행 단계

### 1단계. 채용공고·내 경험 목록 확인 — 전문가: `study-career-mentor`(학습·진로 멘토)
- **위임**: `study-career-mentor` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 핵심 맥락(학년, 졸업 시점, 이 지원이 진로 계획에서 어떤 위치인지)이 빠져 있으면 꼭 필요한 질문만 하고, 빈칸을 추측으로 채우지 않는다.
  - "말하는 목표"와 "진짜 목표"를 구분한다. 이 직무를 왜 원하는지 한 문장으로 말하지 못하면 지원동기 항목이 약해진다.
  - 경험을 시간순으로 다 늘어놓지 않고, 공고 요건과 연결될 만한 것만 골라 "경험 카드"로 정리한다. 카드마다 상황·과제·행동·결과(STAR)를 한 줄씩 적는다.
  - 수치(참여 인원, 기간, 개선 폭)를 모르면 지어내지 않고 [확인 필요: ?]로 남긴다.
  - 자기소개서 마감까지 남은 날짜를 확인해 오늘 할 일 하나를 정한다.
- **이 단계 산출물**: 경험 카드 목록

  | 번호 | 경험 이름 | 상황·과제 | 내가 한 행동 | 결과(수치) | 연결될 공고 요건 |
  | --- | --- | --- | --- | --- | --- |
  | 1 | | | | [확인 필요: ?] | |

- **다음 단계로 넘길 것**: 채용공고 원문, 경험 카드 목록, 채용 유형, 항목별 글자 수 제한

### 2단계. 항목별 자기소개서 초안 — 전문가: `resume-coach`(자기소개서·이력서 코치)
- **위임**: `resume-coach` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 공고에서 필수 자격, 우대 사항, 도구, 담당 업무, 반복되는 키워드를 뽑아 중요도 순으로 세운다. 모든 단어를 똑같이 다루지 않는다.
  - 요건마다 경험 카드를 대응시키고 강함 / 부분 / 근거 없음 / 무관으로 표시한다. "근거 없음"인 키워드는 자기소개서에 쓰지 않는다.
  - 항목마다 소제목 한 줄을 붙이고, 상황·과제 → 행동 → 결과 → 직무 연결 순서로 2~4문단을 쓴다. 담당 업무 나열이 아니라 행동과 결과 중심으로 쓴다.
  - 공고의 표현(직무 핵심 역량, 도구, 자격증 이름)은 사실인 범위에서 그대로 쓴다.
  - NCS 기반 공공기관이면 직무기술서의 능력단위와 필요 지식·기술·태도에 항목을 하나씩 대응시킨다.
  - 블라인드 채용이면 출신 학교·가족 관계·사진·출신 지역 등 기재 금지 정보를 본문에서 완전히 뺀다. 인턴·공채는 직무 관련 활동과 성장 가능성을 앞세운다.
  - 유사도 검사에 걸리기 쉬운 상투적 문장("어릴 때부터 저는…", "귀사의 발전에 기여…")을 피한다.
- **이 단계 산출물**: 직무 적합도 분석 + 자기소개서 항목 초안

  ```markdown
  ## 직무 적합도 분석: [목표 직무]
  **목표 직무**: [직무명, 기관·기업, 채용 유형]
  **적합도 요약**: [강한 적합 / 부분 적합 / 도전, 근거]
  | 요구 역량·자격 | 지원자 근거 | 격차 / 조치 |
  |---|---|---|

  ## 자기소개서: [기관·직무]
  ### 1. [항목 질문 그대로] (글자 수: [제한])
  [소제목 한 줄]
  [상황·과제 → 행동 → 결과 → 직무 연결, 2~4문단]
  ```

- **다음 단계로 넘길 것**: 자기소개서 초안, 적합도 분석표, "확인 필요" 목록

### 3단계. 다듬기·이력서 정리 — 전문가: `resume-coach`(자기소개서·이력서 코치)
- **위임**: `resume-coach` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 모든 문장이 사용자가 준 경험 카드로 뒷받침되는지 한 줄씩 확인한다. 근거 없는 주장은 삭제하거나 [확인 필요]로 바꾼다.
  - 항목별 글자 수를 세어 제한 안에 맞춘다. 공백 포함·제외 기준을 공고에서 확인한다.
  - 약한 문장은 "행동 + 범위 + 수치·결과 + 맥락"으로 다시 쓰고, 큰 수정마다 짧은 이유를 붙인다.
  - 이력서는 표준 순서(인적사항 → 학력 → 경력·인턴 → 자격증·어학 → 대외활동·프로젝트·수상)로 정리하고, 직무를 뒷받침하는 항목만 남긴다. 블라인드면 허용 항목만 적는다.
  - 자기소개서 내용을 바탕으로 면접에서 나올 질문 3개와 답변 포인트를 뽑는다.
  - 대학 취업지원센터의 첨삭·모의면접 프로그램 이용을 안내한다.
- **이 단계 산출물**: 문장 재작성 매트릭스 + 이력서 + 변경 이력

  ```markdown
  ## 문장 재작성 매트릭스
  | 원문 | 수정문 | 효과 |
  |---|---|---|

  ## 이력서
  - 인적사항: [블라인드 채용이면 허용 항목만]
  - 학력: [학교·전공·기간·학점(요구 시)]
  - 경력·인턴: [기관 - 직무 - 기간] / [행동 + 범위 + 결과]
  - 자격증·어학: [직무 관련만]
  - 대외활동·프로젝트·수상: [직무를 뒷받침하는 것만]

  ## 변경 사항
  - [변경] - [뒷받침하는 요건]
  ## 확인 필요
  - [더 강한 주장을 하기 전에 필요한 수치·도구·증빙]
  ```

- **다음 단계로 넘길 것**: 없음(최종 산출물로 전달)

## 최종 산출물
- 직무 적합도 분석표(요구 역량 ↔ 내 근거 ↔ 격차)
- 자기소개서 항목별 초안(글자 수 제한 준수, 소제목 포함)
- 정리된 이력서(채용 유형에 맞는 항목만)
- 변경 이력과 "확인 필요" 목록, 면접 예상 질문 3개
- 파일로 필요하면 자기소개서와 이력서를 각각 마크다운으로 저장하고, DOCX가 필요하면 pandoc 또는 문서 작성 도구로 변환한다.

## 하지 말 것
- 없는 사실·수치·법령 조항 번호를 지어내지 않는다. (공통)
- 개인정보(이름·학번·연락처)를 예시나 결과에 넣지 않는다. (공통)
- **없는 경험을 지어내지 않는다.** 사용자가 말하지 않은 인턴, 프로젝트, 자격증, 리더 역할, 수치는 한 줄도 쓰지 않는다. 근거가 없으면 [확인 필요]로 남기거나 격차로 표시한다.
- 블라인드 채용에서 출신 학교·가족·사진 등 금지 정보를 우회해 드러내는 표현을 쓰지 않는다.
- 서류 통과나 합격을 보장하는 말을 하지 않는다.
