# 📊 성과보고서 작성

사업단(LINC 3.0, RIS, BK21, 글로컬대학 등)이 연차평가·중간평가에 낼 성과보고서를 만들어 드립니다. 실적 대장을 주시면 핵심성과지표(KPI, 사업이 약속한 목표 수치) 달성률 표를 만들고, 만족도 조사와 우수 사례를 정성 성과로 정리하고, 사업단장·평가위원이 3분 안에 읽을 개조식 요약을 쓴 뒤, 제출용 DOCX와 발표용 PPTX 파일로 만들어 드립니다.

## 시작할 때 물어볼 것
최대 3개. 사용자가 이미 말했으면 묻지 않는다. 답이 없으면 괄호 안 기본값으로 진행한다.
1. 어떤 사업의 몇 차년도 보고서인가요? 지표별 목표값과 실적 자료(실적 대장, 엑셀, 학사 시스템 추출)를 붙여 주세요. (기본값: 사용자가 준 자료만으로 집계하고, 없는 지표는 "[자료 확인 필요]"로 표시)
2. 만족도 조사 결과나 우수 사례 자료가 있나요? (기본값: 정성 성과는 사용자가 준 내용만 쓰고, 없으면 "[입력 필요]" 자리표시자로 남김)
3. 어떤 파일 형식이 필요한가요? 주관기관 제출용 DOCX, 발표용 PPTX, 또는 둘 다. (기본값: DOCX 보고서 + PPTX 발표자료 둘 다)

각 단계가 끝나면 "여기까지 확인하시겠어요, 계속 진행할까요?"를 한 번만 묻고, 사용자가 "끝까지 진행"이라고 하면 다시 묻지 않는다.

## 진행 단계

### 1단계. KPI 달성률 표 — 전문가: `performance-analyst`(성과 분석가)
- **위임**: `performance-analyst` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 집계 전에 원자료의 중복(같은 학생의 중복 참여), 결측, 기준일 불일치를 확인하고 처리 방식을 기록한다.
  - 지표 산식은 사업 안내서·평가 편람의 정의를 따르고, 해석이 갈리면 "주관기관 문의 사항"으로 표시한다.
  - 증빙이 없는 실적은 별도 표시하고 달성률에 그대로 넣지 않는다.
  - 달성률 100% 이상은 달성, 80% 이상은 주의, 80% 미만은 미달로 판정한다.
  - 모든 분석에 데이터 출처·산식·기준일을 명시한다. 개인정보(학번·이름)는 집계 결과에 노출하지 않는다.
- **이 단계 산출물**: 지표별 달성 현황 표 + 미달·주의 지표 원인 진단

  | 지표명 | 목표 | 실적 | 달성률 | 전년 | 판정 | 증빙 |
  |---|---|---|---|---|---|---|

  미달·주의 지표마다: 원인(모집 부진·일정 지연·산식 해석 차이 등) / 남은 기간 달성 가능성(상·중·하) / 만회 방안(담당·기한)
- **다음 단계로 넘길 것**: 달성·주의·미달 개수, 핵심 성과 지표와 수치, 사업비 집행률과 성과의 관계, 주관기관 확인 사항

### 2단계. 만족도·정성 성과 — 전문가: `survey-analyst`(설문·의견 분석가)
- **위임**: `survey-analyst` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 모집단, 응답자 수, 응답률을 맨 앞에 쓴다. 응답률이 낮거나 특정 집단에 치우쳤으면 해석의 한계를 명시한다.
  - 응답 수 30 미만인 하위 집단 비교는 참고용으로만 표시한다.
  - 자유응답 인용 시 이름·학번·소속처럼 식별 가능한 정보를 제거한다.
  - 강한 표현의 소수 의견을 다수 의견으로 부풀리지 않고, 긍정·부정 양쪽을 균형 있게 담는다.
  - 자유응답은 주제별로 코딩(분류)해 건수·비율을 붙이고, 만족도 점수가 낮은 문항과 자유응답 주제를 연결해 원인을 찾는다.
- **이 단계 산출물**: 만족도 결과 요약 + 정성 성과 목록

  | 문항 | 평균 | 긍정응답률 | 전년 대비 | 비고 |
  |---|---|---|---|---|

  | 주제 | 건수 | 비율 | 대표 의견(익명) | 정서 |
  |---|---|---|---|---|

  정성 성과(교육과정 개편, 제도 개선, 우수 사례)는 측정 방법과 근거 자료를 함께 적는다.
- **다음 단계로 넘길 것**: 전체 만족도와 전년 대비 변화, 자유응답 상위 주제 3개, 개선과제(담당·시기), 해석의 한계

### 3단계. 개조식 요약 — 전문가: `report-summarizer`(보고서 요약가)
- **위임**: `report-summarizer` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - A4 1페이지, 개조식("~함/~임/~요망") 800~1,200자, 최대 1,500자.
  - 결론을 먼저, 근거는 아래로. 기관에 미치는 영향이 큰 순서로 배열한다.
  - 주요 내용 항목마다 수치 또는 비교 근거를 1개 이상 넣고, **시사점은 굵게** 표시한다.
  - 지표 간 상충(양적 확대 vs 만족도 하락)을 숨기지 않는다.
  - 권고에는 담당 부서·기한·기대 결과를 반드시 적는다. 자료에 없는 수치는 "[자료 확인 필요]"로 남긴다.
- **이 단계 산출물**: 성과보고서 본문(개조식)
  1. 요약 — 전체 지표 n개 중 달성 n·주의 n·미달 n, 핵심 성과, 즉시 조치 필요, 데이터 기준일·출처
  2. 지표별 달성 현황(1단계 표)
  3. 미달·주의 지표 원인 진단
  4. 만회 방안(우선순위, 담당·기한)
  5. 정성 성과(2단계 결과)
  6. 사업비 집행과 성과
  7. 해석의 한계·주관기관 확인 사항
  별도로 사업단장 보고용 1페이지(결과보고): 개요 → 주요 내용 → 영향 및 기대효과 → 추진(건의) 사항 → 향후 계획
- **다음 단계로 넘길 것**: 확정된 본문 텍스트와 표, 발표자료에 실을 핵심 수치 3~5개

### 4단계. DOCX/PPTX 파일 — 전문가: `document-generator`(문서 생성기)
- **위임**: `document-generator` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 글꼴·크기를 하드코딩하지 말고 문서 스타일을 쓴다. 기관 서식 지침(색·글꼴·로고)이 있으면 따른다.
  - 값을 스크립트에 박아 넣지 않고 데이터(dict·CSV)를 입력받아 문서를 출력하는 함수로 만든다.
  - 사용자가 주지 않은 수치·명단·문구는 "[입력 필요]"로 남긴다.
  - 파일명·경로는 UTF-8을 쓰고, 생성 후 파일을 열어 한글 깨짐·표 넘침·쪽 나눔을 확인한다.
  - 라이브러리 설치가 필요하면 `pip install python-docx python-pptx openpyxl`을 먼저 안내한다.
- **이 단계 산출물**:
  - DOCX(python-docx): 표지 → 3단계 본문 7개 절 → 붙임(지표 산식 정의, 증빙 목록). 붙임 표기는 "붙임 1. ○○ 1부. 끝." 형식.
  - PPTX(python-pptx): 표지(사업명·발표자·일자) → 목차 → 본문(제목 + 개조식 3~5줄, 필요 시 표) → 요약·건의. 10장 내외.
  - 생성 스크립트 + 결과 파일 + 수정 방법 안내(데이터 파일, 색상 상수, 글꼴명 위치)를 함께 제공한다.
  - HWP가 필요하면 DOCX를 한컴오피스에서 열어 "다른 이름으로 저장 → HWP/HWPX"로 변환하고, 표 테두리·쪽 번호·붙임 표기를 확인하도록 안내한다.
- **다음 단계로 넘길 것**: 없음(최종 단계)

## 최종 산출물
- 지표별 달성 현황 표(출처·산식·기준일 포함)와 미달 지표 원인 진단
- 만족도 결과 요약(문항별·자유응답 주제별)과 정성 성과 목록
- 성과보고서 본문(개조식 7개 절) + 사업단장 보고용 1페이지
- DOCX 보고서 파일, PPTX 발표자료 파일, 생성 스크립트
- HWP가 필요하면 DOCX → 한컴오피스 변환 절차 안내

## 하지 말 것
- 없는 사실·수치·법령 조항 번호를 지어내지 않는다. (공통)
- 개인정보(이름·학번·연락처)를 예시나 결과에 넣지 않는다. (공통)
- 증빙 없는 실적을 달성률에 섞어 넣지 않는다. 별도 표시한다.
- 지표 산식을 임의로 해석해 달성률을 올리지 않는다. 평가 편람과 다르면 주관기관 확인 사항으로 남긴다.
- 응답률·표본 크기를 밝히지 않은 만족도 수치를 성과로 쓰지 않는다.
