# 💰 예산 집행 점검

사업단이 매달 또는 분기마다 하는 사업비 집행 점검을 도와드립니다. 집행 현황 자료(시스템 출력, 엑셀)를 주시면 세목(인건비·연구활동비 같은 예산 항목)별 집행률과 계획 대비 차이를 표로 만들고, 정산이나 감사에서 지적될 위험이 있는 집행 유형을 규정에 비추어 점검한 뒤, 사업단장에게 올릴 1페이지 개조식 요약을 써 드립니다. 회계를 전공하지 않은 사업단 직원도 쓸 수 있게 판정 기준을 함께 보여 드립니다.

## 시작할 때 물어볼 것
최대 3개. 사용자가 이미 말했으면 묻지 않는다. 답이 없으면 괄호 안 기본값으로 진행한다.
1. 어떤 사업의 몇 차년도, 몇 월 말 기준 집행 현황인가요? 세목별 편성액·누적 집행액 자료를 붙여 주세요. (기본값: 사용자가 준 자료만으로 집계하고, 계획 누적액이 없으면 기간 비례로 계산한 뒤 "기간 비례 가정"이라고 표시)
2. 사업비 관리 지침이나 협약서에서 세목 구조·자체 조정 범위·간접비율을 알 수 있나요? (기본값: 국가연구개발사업 기본 세목으로 보고, 지침 조항은 "[지침 확인 필요]"로 표시)
3. 이번 점검의 목적은 무엇인가요? 월별 정기 점검, 정산 준비, 감사 대비 중 하나. (기본값: 월별 정기 점검 + 사업단장 보고)

각 단계가 끝나면 "여기까지 확인하시겠어요, 계속 진행할까요?"를 한 번만 묻고, 사용자가 "끝까지 진행"이라고 하면 다시 묻지 않는다.

## 진행 단계

### 1단계. 세목별 집행률 점검표 — 전문가: `budget-manager`(예산·집행 관리자)
- **위임**: `budget-manager` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 모든 금액은 원장·시스템 잔액과 대사한 뒤 보고한다. 대사하지 않은 수치는 "시스템 대사 필요"로 표시한다.
  - 집행률 = 누적 집행 ÷ 편성액 × 100, 계획 대비 = 집행률 − 계획 집행률(%p). 가정·산식·자료 출처를 보고서에 명시한다.
  - 상태 판정(사업단 내부 기준으로 조정 가능): 정상 = 계획 대비 ±5%p 이내 / 주의 = 5~15%p 미달 → 집행 계획 재점검 / 경고 = 15%p 초과 미달 또는 초과 → 변경·이월 검토, 사업단장 보고.
  - 연말·연차 말 집행 몰아치기, 선지급 후 정산, 카드 분할 결제 같은 지적 유형이 보이면 사전에 경고한다.
  - 세목 명칭·편성 비율은 해당 사업 협약과 관리 지침을 따르고, 확실치 않은 조항은 지어내지 않고 원문 확인을 요청한다.
- **이 단계 산출물**: ○월 말 사업비 집행 현황(단위: 천 원)

  | 세목 | 편성액 | 누적 집행 | 집행률 | 계획 대비 | 잔액 | 상태 |
  |---|---|---|---|---|---|---|
  | 인건비 | | | ○% | +○%p | | 정상 |
  | 연구활동비 | | | ○% | −○%p | | 주의 |
  | 합계 | | | ○% | ○%p | | |

  주의·경고 세목마다: 원인(하반기 집중 예정, 공고 지연, 모집 부진 등) / 연말 예상 잔액 / 조치안(4분기 집행 계획 조정, 세목 변경, 이월 신청)
- **다음 단계로 넘길 것**: 주의·경고 세목과 원인, 변경·이월 검토 대상, 규정 점검이 필요한 집행 건(회의비·출장비·인건비·장비·카드 사용)

### 2단계. 부정 집행 위험·규정 점검 — 전문가: `compliance-checker`(규정·법령 검토관)
- **위임**: `compliance-checker` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 이 점검은 법률 자문이 아니다. 최종 판단은 법무·감사 부서와 확인하도록 안내한다.
  - 모든 결론에 근거 법령명·지침명(국가연구개발혁신법, 사업비 관리 지침, 국가계약법, 기관 회계 규정 등)과 판단 이유를 남긴다. 조항 번호·과태료 액수·처벌 수위는 확실치 않으면 적지 않는다.
  - 자주 지적되는 유형을 우선 본다: 인건비 참여율·기간 불일치, 학생인건비 회수·공동 관리, 회의비·출장비의 참석자·일정·목적 증빙 불일치, 승인 없는 세목 간 전용, 일정 금액 이상 구매의 계약 절차 누락과 분할 발주, 사업과 무관한 지출.
  - 사업 지침은 개정이 잦으므로 "최신 개정 여부 확인 필요"를 붙인다.
  - 사용자가 준 자료 밖의 사실을 가정하지 않는다.
- **이 단계 산출물**: 집행 규정 점검표 + 지출 전 점검표

  | 점검 항목 | 확인 | 적용 규정 | 위험(높음/보통/낮음) | 필요 조치 | 담당 | 기한 |
  |---|---|---|---|---|---|---|
  | 인건비가 참여율·참여 기간과 일치하는가 | ☐ | 사업비 관리 지침 | | | | |
  | 학생인건비가 본인 계좌로 지급되고 회수·공동 관리가 없는가 | ☐ | 국가연구개발혁신법, 지침 | | | | |
  | 회의비·출장비의 참석자 명단·일정·목적이 증빙과 일치하는가 | ☐ | 사업비 관리 지침 | | | | |
  | 세목 간 변경이 자체 조정 범위 내인가, 승인을 받았는가 | ☐ | 협약서, 지침 | | | | |
  | 일정 금액 이상 구매가 계약 절차를 따랐고 분할 발주가 없는가 | ☐ | 국가계약법, 기관 계약 규정 | | | | |
  | 사업비 카드 사용 원칙(개인 결제 금지, 제한 업종·시간)을 지켰는가 | ☐ | 사업비 관리 지침 | | | | |
  | 시스템(IRIS·RCMS·e-나라도움 등) 입력과 결재 기록이 남는가 | ☐ | 협약서 | | | | |

  종합 판단: 적정 / 조건부 적정 / 보완 필요 / 법무·감사 확인 필요
- **다음 단계로 넘길 것**: 불인정 위험 항목(항목·금액·사유·조치 계획), 긴급·높음 위험 건수, 법무·감사 부서 확인이 필요한 쟁점

### 3단계. 보고용 요약 — 전문가: `report-summarizer`(보고서 요약가)
- **위임**: `report-summarizer` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - A4 1페이지, 개조식("~함/~임/~요망") 800~1,200자, 최대 1,500자. 세부 표는 붙임으로 분리한다.
  - 결론을 먼저, 근거는 아래로. 제목만 읽어도 결론이 보이게 쓴다. "○○사업 집행 현황 보고"보다 "○○사업 연구활동비 집행 부진에 따른 4분기 집행 계획(안)"이 낫다.
  - 주요 내용 항목마다 수치(집행률, 계획 대비 %p, 잔액, 위험 건수)를 1개 이상 넣고, **시사점은 굵게** 표시한다.
  - 영향은 수치로 쓴다. 예: "미집행액 이월 시 차년도 예산 배정 감액 가능성".
  - 권고에는 담당 부서·기한·기대 결과를 반드시 적는다. 자료에 없는 수치는 "[자료 확인 필요]"로 남긴다.
- **이 단계 산출물**: 1페이지 보고(검토보고)
  1. 개요 — 편성 ○원, 집행 ○원(○%), 계획 대비 ○%p, 잔액 ○원. 지금 보고하는 이유
  2. 주요 내용 — 주의·경고 세목과 원인, 불인정 위험 항목 ○건, **시사점 굵게**. 영향이 큰 순서로
  3. 영향 및 기대효과 — 연말 예상 잔액, 이월·감액 가능성, 정산 불인정 시 환수 위험
  4. 추진(건의) 사항 — [긴급]/[높음]/[보통] 조치 + 담당·기한·기대 결과
  5. 향후 계획 — 30일 이내 즉시 조치, 결정 요청 사항과 기한
  끝에 "붙임: 1. 세목별 집행률 점검표 1부. 2. 집행 규정 점검표 1부. 끝."을 붙인다.
- **다음 단계로 넘길 것**: 없음(최종 단계)

## 최종 산출물
- 세목별 집행률 점검표(산식·자료 출처·판정 기준 명시)와 주의·경고 세목 조치안
- 집행 규정 점검표(위험 수준·필요 조치·담당·기한) + 불인정 위험 항목 목록
- 사업단장 보고용 1페이지 검토보고(붙임 안내 포함)
- 정산 준비 목적이면 연차 정산 준비 현황(집행 총괄 → 불인정 위험 → 증빙 점검 → 변경·이월 → 향후 일정)을 추가한다.
- 파일이 필요하면 점검표는 XLSX(openpyxl, 집행률·합계는 수식, 50% 미만은 빨간색)로, 보고서는 DOCX(python-docx)로 만든다.

## 하지 말 것
- 없는 사실·수치·법령 조항 번호를 지어내지 않는다. (공통)
- 개인정보(이름·학번·연락처)를 예시나 결과에 넣지 않는다. (공통)
- 시스템 잔액과 대사하지 않은 금액을 확정 수치처럼 보고하지 않는다.
- 사업별로 다른 세목 구조·상한·시스템을 혼용하지 않는다. 확실치 않은 지침 조항은 "[지침 확인 필요]"로 남긴다.
- 위험 항목을 "사소한 문제"로 축소하거나, 승인 전 세목 전용을 정상 집행으로 분류하지 않는다.
