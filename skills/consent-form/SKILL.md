# 🔐 개인정보 동의서 만들기

설문조사, 행사 참가 신청, 사업 참여기업 등록, 프로그램 참여자 명단처럼 개인정보를 모아야 할 때 필요한 동의서를 만들어 드립니다. 개인정보를 처음 다루는 행정직원, 사업단 담당자, 공공기관 실무자를 위한 스킬입니다. "어떻게 보호할까"보다 "이 정보가 정말 필요한가"를 먼저 따져 항목을 줄이고, 법이 요구하는 고지사항을 빠짐없이 넣은 뒤, 서식 파일로 만들어 드립니다. 이 스킬의 검토는 법률 자문이 아니며 최종 확인은 기관의 개인정보 보호책임자(CPO)·법무 부서와 합니다.

## 시작할 때 물어볼 것
1. 어떤 업무에서, 누구의(재학생·교직원·외부인·기업 담당자 등) 정보를, 왜 모으나요? (기본값: 없으면 진행 불가. 이것만은 꼭 묻는다)
2. 모으려는 항목을 전부 알려 주세요. 외부 업체나 다른 기관에 넘기는 일이 있나요? (기본값: 제3자 제공·위탁 없음)
3. 소속 기관이 공공기관(국공립대·공공기관 지정)인가요, 사립대인가요? (기본값: 공공기관 기준으로 작성)

각 단계가 끝나면 "여기까지 확인하시겠어요, 계속 진행할까요?"를 한 번만 묻고, 사용자가 "계속"이라고 하면 이후 단계는 멈추지 않고 진행합니다.

## 진행 단계

### 1단계. 수집 항목 최소화 검토 — 전문가: `privacy-officer`(개인정보보호 담당관)
- **위임**: `privacy-officer` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 항목마다 "왜 필요한가"를 묻고, 목적 달성에 꼭 필요하지 않은 항목은 삭제를 권한다. 덜 모으는 것이 가장 강력한 보호조치다.
  - 주민등록번호 등 고유식별정보, 건강·사상 등 민감정보는 법령 근거나 별도 동의 없이 넣지 않는다. 대부분의 설문·행사에는 필요 없다.
  - 처리 근거를 정한다: 정보주체 동의 / 법령상 의무 / 계약 이행 / 공공기관 소관 업무. 학점·장학금과 연계돼 사실상 강제되는 동의는 자유로운 동의로 보기 어려우니 법령·계약 근거 쪽을 권한다.
  - 만 14세 미만이 포함되면 법정대리인 동의가 필요함을 표시한다.
  - 보유기간은 목적 달성 시점 또는 기록물 관리 기준에 맞춰 정하고, 근거를 적는다.
  - 외부 업체(설문 도구·클라우드 등)를 쓰면 위탁이고, 다른 기관에 넘기면 제3자 제공이다. 둘을 구분해 표시한다.
- **이 단계 산출물**: 항목 검토표

| 항목 | 필수/선택 | 필요 이유 | 판단(유지·삭제·선택으로 변경) | 구분(일반·고유식별·민감) |
|---|---|---|---|---|
| 예: 이름 | 필수 | 참가자 확인 | 유지 | 일반 |
| 예: 주민등록번호 | | | 삭제 권고(생년월일로 대체) | 고유식별 |

- **다음 단계로 넘길 것**: 확정된 수집 항목(필수·선택), 처리 근거, 보유기간, 위탁·제3자 제공 여부

### 2단계. 동의서 초안 작성 — 전문가: `privacy-officer`(개인정보보호 담당관)
- **위임**: `privacy-officer` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 필수 고지사항 5가지를 빠짐없이 넣는다: ① 수집·이용 목적 ② 수집 항목(필수·선택 구분) ③ 보유·이용 기간 ④ 동의를 거부할 권리 ⑤ 거부 시 불이익 내용.
  - 제3자 제공이 있으면 **별도 항목**으로 제공받는 자·제공 목적·제공 항목·보유기간·거부권과 불이익을 쓰고 동의란을 따로 둔다.
  - 고유식별정보·민감정보는 별도 동의란으로 분리한다. 홍보·안내 발송(문자·이메일) 동의는 필수 동의와 묶지 않고 선택 동의란으로 뺀다.
  - 문장은 초보자도 이해할 수 있게 쉽게, 항목은 표로 정리한다. 조항 번호를 지어내지 않고 법령명만 쓴다.
- **이 단계 산출물**: 동의서 초안(아래 골격)

```
개인정보 수집·이용 동의서 — [업무명]

[기관명]은(는) 개인정보보호법에 따라 아래와 같이 개인정보를 수집·이용하고자 합니다. 내용을 읽고 동의 여부를 표시해 주세요.

1. 개인정보 수집·이용 (필수)
| 수집·이용 목적 | 수집 항목 | 보유·이용 기간 |
|---|---|---|
| [구체적 목적] | 필수: [항목] / 선택: [항목] | [기간 또는 "목적 달성 후 지체 없이 파기"] |
※ 동의를 거부할 권리가 있으며, 거부 시 [불이익 내용, 예: 프로그램 참여 불가]. 선택 항목 거부 시 불이익은 없습니다.
□ 동의함  □ 동의하지 않음

2. 개인정보 제3자 제공 (해당 시)
| 제공받는 자 | 제공 목적 | 제공 항목 | 보유·이용 기간 |
|---|---|---|---|
※ 거부할 권리와 거부 시 불이익: [내용]
□ 동의함  □ 동의하지 않음

3. 홍보·안내 수신 동의 (선택)
□ 동의함  □ 동의하지 않음

(14세 미만 아동은 법정대리인 동의란 추가)
[YYYY. MM. DD.]  성명: ________  (서명)
```

- **다음 단계로 넘길 것**: 동의서 초안, 항목 검토표, 위탁·제3자 제공 여부

### 3단계. 규정 점검 — 전문가: `compliance-checker`(규정·법령 검토관)
- **위임**: `compliance-checker` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - 이 점검은 법률 자문이 아니다. 조항 번호·과태료 액수를 확실히 모르면 적지 않고 "개인정보보호법상 확인 필요"로 표시한다. 개정이 잦은 영역은 "최신 개정 여부 확인 필요"를 붙인다.
  - 검토 결론마다 근거 법령명(또는 기관 규정명)과 판단 이유를 남긴다.
  - 위탁이 있으면 위탁 계약서와 개인정보처리방침 공개가 필요함을, 공공기관이면 개인정보 파일 등록이 필요함을 표시한다.
  - 판단이 갈리는 사안은 "CPO·법무 부서 확인 필요"로 넘긴다.
- **이 단계 산출물**: 개인정보 처리 점검표(에이전트 서식)

| 점검 항목 | 확인 | 근거 | 비고 |
|---|---|---|---|
| 수집 목적이 구체적으로 정해져 있는가 | ☐ | 개인정보보호법 | |
| 수집 항목이 목적에 필요한 최소한인가 | ☐ | 개인정보보호법 | 주민등록번호 수집 여부 별도 확인 |
| 동의서에 목적·항목·보유기간·거부권이 명시됐는가 | ☐ | 개인정보보호법 | |
| 민감정보·고유식별정보는 별도 동의를 받는가 | ☐ | 개인정보보호법 | |
| 보유기간과 파기 절차가 정해져 있는가 | ☐ | 개인정보보호법, 공공기록물관리법 | |
| 외부 위탁 시 위탁 계약과 공개가 이루어지는가 | ☐ | 개인정보보호법 | |
| 제3자 제공 시 별도 동의 또는 법적 근거가 있는가 | ☐ | 개인정보보호법 | |

- **다음 단계로 넘길 것**: 점검 결과 반영한 동의서 최종안, "확인 필요" 항목 목록

### 4단계. DOCX 파일 만들기 — 전문가: `document-generator`(문서 생성기)
- **위임**: `document-generator` 서브에이전트가 설치되어 있으면 그에게 맡긴다. 없으면 아래 요령으로 직접 한다.
- **요령**:
  - `python-docx`로 만든다. 설치가 필요하면 `pip install python-docx`를 먼저 알린다. 글꼴은 Normal 스타일에 맑은 고딕 11pt.
  - 목적·항목·기간 표와 동의 체크란(□ 동의함 □ 동의하지 않음), 날짜·성명·서명란을 갖춘다. 서명·직인은 만들지 않는다.
  - 기관명·업무명·항목을 데이터로 받아 채우는 함수로 만들어 다른 사업에도 재사용할 수 있게 한다. 사용자가 주지 않은 값은 "[입력 필요]"로 남긴다.
  - 파일을 열어 표 넘침, 한글 깨짐, 1~2쪽 안에 드는지 확인한다.
  - HWP가 필요하면 한컴오피스 한글에서 DOCX를 열어 "다른 이름으로 저장 → HWP/HWPX"로 변환하도록 안내한다.
- **이 단계 산출물**: `개인정보동의서_[업무명].docx` + 생성 스크립트 + 수정 방법 안내
- **다음 단계로 넘길 것**: 없음(마무리)

## 최종 산출물
- 항목 검토표(삭제·변경 권고 포함)와 확정된 처리 근거·보유기간
- 법정 고지사항이 모두 들어간 동의서 최종안(필수·선택·제3자 제공·수신 동의란 분리)
- 개인정보 처리 점검표와 "CPO·법무 확인 필요" 항목 목록
- DOCX 파일과 생성 스크립트. HWP는 DOCX를 한컴오피스에서 변환

## 하지 말 것
- 없는 사실·수치·법령 조항 번호를 지어내지 않는다. (공통)
- 개인정보(이름·학번·연락처)를 예시나 결과에 넣지 않는다. (공통)
- 필요성이 확인되지 않은 항목, 특히 주민등록번호·건강 정보를 "혹시 필요할까 봐" 넣지 않는다.
- 필수 동의와 선택 동의(홍보 수신·제3자 제공)를 한 칸에 묶지 않는다.
- 이 스킬의 결과를 법률 자문으로 표현하지 않는다. 최종 확인은 CPO·법무 부서와 한다.
